# 0.2.0 界面与集成规格

本版依据已确认的任务看板需求，使用 `board-concept.png` 的首页布局和 `detail-concept.png` 的右侧验收抽屉。抽屉背景沿用首页，不采用生成图中额外的任务和日期。

- 页面背景 `#f7f8fa`，栏背景 `#eef0f2`，小卡白色，大卡 `#f4f5f6`；文字 `#202329`，次文字 `#656b74`，边线 `#d9dde2`，主按钮 `#292d32`。
- 字体 Segoe UI、Microsoft YaHei、无衬线；页标题 30px，栏标题 20px，卡标题 16px，正文与控件 14px，次文字 13px。桌面抽屉标题 28px、验收标题 20px、标准正文 16px；小屏依次缩至 24px、18px、14px。
- 1536px 页面左右边距 28px，顶栏 68px、展开信息栏 44px，五栏间距 16px；卡边距 16px，圆角 6px。抽屉宽 550px，完整高度，正文可滚动、操作栏固定。
- 首页文案：个人管家、任务看板、搜索项目或任务、设置、新建项目、已展开、收起子任务、灵感池、待启动、进行中、待验收、已结项、查看、下一步、验收、主聊天。
- 详情文案：任务说明、验收与成果、主聊天、资料、验收标准、由 AI 拟定，可编辑后确认、我已确认以上验收标准、交付成果、尚未交付成果、修改意见、退回、开始执行。
- 使用 Lucide 轮廓图标，18px、1.7px 线宽。状态点仅用于运行、需处理与结项，不新增无关统计。
- 首页概念图的栏数字与示例卡数量不一致；实现采用真实卡数量。空库显示新建项目入口。小屏横向浏览五栏，保留阶段顺序；抽屉占满屏幕。

Codex 集成使用官方 App Server JSON-RPC 标准输入输出传输，继承已有 Codex 登录和权限设置，不另配 API Key。所有插件实例通过同一个仅监听本机的服务协调任务；服务读取真实事件、保留主聊天 ID、继续原聊天，并在收到中断完成信号后回退阶段。

2026-10-02 已实测 initialize、account/read、thread/list：本机 ChatGPT 登录可用，F:\workspace 聊天可读。另完成 ephemeral 只读结构化模型回合和两个 MCP 客户端共用服务的并发保存验证。桌面控制套接字当前连接失败。原生主聊天跳转需在桌面重新加载插件后验证，浏览器 QA 不自动打开 codex:// 链接。

执行结束不自动代表交付。主聊天通过插件提交按验收标准逐条列举的交付证据；真实 turn/completed 之后才进入待验收。未提交、证据不齐、失败或等待回复均保留进行中。停止失败时保留真实阶段并显示原因。

官方依据：

- https://developers.openai.com/codex/app-server
