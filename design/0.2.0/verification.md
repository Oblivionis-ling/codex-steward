# 0.2.0 实现与验证记录

日期：2026-10-02。版本按本轮确认的五栏基础、大卡项目、小卡任务、主聊天及用户验收闭环实现。0.1.0 已先上传私有 GitHub 仓库并保存 v0.1.0 标签。

## 实现约定

- 已结项项目「重新打开并追加需求」回待启动，保留历史小卡阶段；显式大卡回退仍是全部小卡停止并统一待启动。
- 已结项任务修改目标前须先回退；待验收任务实质修改自动回待启动。标准 hash、runId、交付 hash共同防止旧成果用于新验收。
- 项目回退占用一次本地原子操作，停止过程中不接受其他窗口的新建或启动。无停止确认时不伪造回退结果。
- 归档行动建议先保存于资料，经用户确认才创建小卡。回顾建议也经点击确认创建。
- 重复提交的同来源、同正文资料不重复保存。已移除资料保留历史来源，但不会继续作为新执行背景。
- 0.1.0 数据读时迁移，首次有效写入保存不可覆盖的原版本快照，再保存 v2。导入恢复阶段与引用，不恢复执行。

## 功能验证与实际限制

构建成功，测试33/33。IAB隔离数据环境验证：空库新项目、AI拆分草案编辑与确认、未确认标准不能启动、AI标准生成、启动后送验、原聊天返工与两轮消息保留、验收结项、运行和已结项小卡一起回退、资料批量归档与确认行动、小卡来源、全文/分类/标签查找、引用打开原文并编辑、只选一个历史聊天后建议新项目、单项目展开、备份导出与合并、首页搜索、深色与小屏。浏览器控制台未发现应用错误。

真实接口验证：本机App Server initialize、account/read、thread/list成功；现有ChatGPT登录可用。ephemeral只读回合返回结构化criteria并真实completed，未使用工具或生成文件。两个MCP客户端并发创建项目，由同一共享HTTP服务保存，验证成功。CLI确认插件0.2.0已安装并启用，缓存MCP配置STEWARD_BROKER=1。

完整交付闭环使用MockCodex模拟实际协议事件与证据，不宣称真实模型已完成项目或真实停止一个正在工作的用户聊天。原生权限请求、RPC失败、中断等待对应turn/completed等边界由客户端测试验证。

本机桌面daemon控制套接字连接失败（Windows os error 10050）；本轮采用官方独立App Server stdio，没有重启或改动桌面daemon。侧栏显示、宿主聊天打开及资料归档写回须在桌面重新加载插件后验证。IAB此前明确拒绝自动打开codex://，本轮未绕过，也未声称端到端桌面导航已验收。
